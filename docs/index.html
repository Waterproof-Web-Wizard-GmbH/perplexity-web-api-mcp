Nine tools: search, ask, reason, research, computer, study, document review, usage, and reading existing threads. File attachments and connectors work with a session cookie.

curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/dhuettner/perplexity-web-api-mcp/releases/latest/download/perplexity-web-api-mcp-installer.sh | sh
claude mcp add perplexity \
  --env PERPLEXITY_SESSION_TOKEN="..." \
  --env PERPLEXITY_SESSION_COOKIE_NAME="__Secure-pplx.session.<uuid>" \
  -- perplexity-web-api-mcp
{
  "command": "perplexity-web-api-mcp",
  "env": {
    "PERPLEXITY_SESSION_TOKEN": "...",
    "PERPLEXITY_SESSION_COOKIE_NAME": "__Secure-pplx.session.<uuid>"
  }
}

No API key?

Correct. The server uses the session of your logged-in Perplexity account, the same way the website does. A free account works; Pro unlocks the Pro models and higher quotas.

Where is the cookie?

Open perplexity.ai, then DevTools, Application, Cookies. Copy the name and value of __Secure-pplx.session.<uuid>. Run perplexity-web-api-mcp --check to confirm the session is accepted.

Which platforms?

Prebuilt binaries for macOS (arm64, x86_64), Linux (x86_64, aarch64), and Windows (x86_64), installed to ~/.cargo/bin. Or cargo install --git from the repository.
